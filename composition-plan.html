Issue badge Shows the Afterhours issue number. Appears after the introduction. Absolute positioning anchors it to the header. The relative feature-header is the containing block. The badge creates a stacking context with z-index 10. Returns to normal flow below 52rem. Check 320px, 768px, 1280px and long titles.
Story navigation Helps readers jump between sections. Appears before the article. Sticky positioning keeps links visible on desktop. The main grid bounds the sticky element. The navigation creates a stacking context with z-index 20. Normal flow below 52rem. Test scrolling, boundaries and keyboard focus.
Pull quote Highlights the main message of the story. Appears between article paragraphs. Relative positioning and negative margin create overlap. The quote remains in normal flow. Relative positioning with z-index 10 creates a stacking context. No overlap below 52rem. Test responsive widths, zoom and longer content.
Rounded feature container Frames the main Afterhours artwork. A rectangular figure with an image and caption. Border-radius softens the edges and matches the design. Normal flow; no new stacking context. Square corners remain readable if unsupported. Check image edges at all viewport sizes.
Clipped feature image Adds an angled editorial appearance. The full image displays as a rectangle. The image stays inside its figure. An active clip-path creates a stacking context. The image stays inside its figure. The @supports rule preserves the rectangular image. Disable clip-path and check that the image remains visible.
Portrait text wrap Connects the artwork with the article text. The image appears above the paragraphs. Float and shape-outside create a circular text wrap. The float remains inside its article section. Rectangular float fallback on desktop; normal flow on mobile. Disable shape-outside and test 320px, 768px, and 1280px.
